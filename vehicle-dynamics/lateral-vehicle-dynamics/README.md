# Lateral vehicle dynamics

A two-degree-of-freedom bicycle model with steering-response and parameter-sensitivity studies.

Open this directory as the working folder and add `codes` to the MATLAB path. Start with `codes/project1.m` and inspect `Sim_project1.slx`; `codes/plot_results.m` expects a simulation output named `out`. The other scripts explore speed, cornering stiffness, and steering cases. MATLAB/Simulink run not verified here.
