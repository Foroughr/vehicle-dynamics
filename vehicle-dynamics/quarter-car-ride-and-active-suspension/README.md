# Quarter-car ride and active suspension

Vehicle ride dynamics, road-profile simulation, parameter studies, and passive versus PID active-suspension comparisons.

Open `sim2.slx` and add the `codes` folder to the MATLAB path. Inspect `codes/init_quarter_car.m` first; it initializes model parameters and generates a Class C random-road profile. Analysis scripts in `codes` produce ride-comfort and active/passive comparisons. Small original input files are in `inputs` for reference. The scripts create result files locally. MATLAB/Simulink execution has not been verified here.
